# 課表查詢與請假調課系統（去個資版）

本系統為純靜態網頁應用程式，所有課表資料在匯入前皆已完成**去個資遮罩（教師姓名中間字改為 `○`，2 字姓名改為 `姓○`）**，可直接部署於 GitHub Pages、學校網頁空間或本機開啟使用。

## 目錄結構
- `index.html` / `styles.css` / `app.js`：前端網頁系統（免後端伺服器）
- `data/115-1.json`：115 學年度第 1 學期去個資課表資料
- `data/default-bundle.js`：預設內嵌資料（讓直接雙擊 `index.html` 也能離線開啟）
- `tools/convert_pdf_to_json.py`：本機 PDF 解析與去個資轉檔腳本
- `tools/轉換課表.bat`：Windows 一鍵雙擊轉檔工具

## 如何每年在本機更新新學年度課表（不上傳個資）
1. 確保電腦已安裝 Python 套件：`pip install pymupdf pdfplumber`
2. 雙擊執行 `tools\轉換課表.bat`（所有處理皆在本機離線完成）。
3. 依提示輸入學年度代碼（如 `115-2`）、顯示名稱，並拖曳新的「教師課表.pdf」與「班級課表.pdf」。
4. 轉檔完成後會產生已去個資的 `data\115-2.json`。
5. 開啟網頁系統，切換至「**📥 學年度匯入與本機去個資工具**」分頁，選擇該 `.json` 檔即可立即更新！

## 調課規則說明
- **全校共同時間排除**：`班會`、`週會`、`團體活動`、`彈性教學`、`彈性學習時間` 已預設標記為不可調課時段。
- **支援一對一對調、連堂優先推薦、前後週跨週對調、三方連環調（三角調課）**，並內建**時段衝突鎖定**與**一鍵複製調課清單**。
